# 日志分析技能

## 描述

分析系统日志和应用日志，提取错误信息，识别异常模式，支持错误分类、频率统计、趋势分析，辅助快速定位服务器、服务、网络、权限等各类线上问题。

## 使用场景

- 服务器日常巡检，自动分析近期日志，筛查潜在异常

- 业务报错、服务卡顿、访问异常时，排查指定时间段日志问题

- 统计日志错误类型、出现频率，分析故障爆发规律与趋势

## 日志采集命令

### 系统日志分析

```bash
# 最近 1000 条系统日志，筛选严重错误、失败、关键异常，保留最新100条
tail -1000 /var/log/syslog | grep -i "error\|fail\|critical" | tail -100

# 按时间维度统计系统错误频次，定位高发异常时段
grep -i "error" /var/log/syslog | awk '{print $1, $2, $3}' | \
  cut -d: -f1,2 | sort | uniq -c | sort -rn | head -20

# 筛查系统OOM内存溢出杀死进程事件
dmesg | grep -i "oom\|out of memory" | tail -20
```

### 应用日志分析（Nginx）

```bash
# 筛选Nginx近期错误日志，过滤无效favicon请求干扰
tail -500 /var/log/nginx/error.log | grep -v "favicon" | tail -50

# 统计Nginx 5xx服务端错误频次
awk '$9 ~ /^5/ {print $9}' /var/log/nginx/access.log | sort | uniq -c | sort -rn

# 统计Nginx慢请求（响应时长大于1秒），排查接口性能问题
awk '$NF > 1.0 {print $7, $NF"s"}' /var/log/nginx/access.log | sort -t' ' -k2 -rn | head -20
```

## 分析策略

### 错误分类、严重程度及处理规范

采集日志后，统一按照以下标准分类定级，并给出对应处理方案：

|错误类别|匹配关键词|严重程度|处理建议|
|---|---|---|---|
|系统资源|OOM、disk full、no space|🔴 严重|立即处理，优先清理磁盘空间、释放内存、终止异常进程，避免服务宕机|
|服务异常|service failed、connection refused|🔴 严重|检查服务运行状态、重启异常服务，排查服务启动失败原因、端口占用问题|
|网络问题|timeout、connection reset|🟡 警告|检查服务器网络、防火墙规则、代理配置、上下游服务连通性|
|权限问题|permission denied、access denied|🟡 警告|核对文件、目录、接口访问权限，修正用户/用户组权限配置|
|配置错误|invalid config、parse error|🟡 警告|检查配置文件语法、参数合法性，修正配置后重启服务|
|一般警告|warning、deprecated|🟢 一般|无需紧急处理，记录归档，后续迭代优化适配即可|

### 趋势识别规则

- 对比**过去1小时**与**过去24小时**的整体错误率、各类别错误占比

- 错误率同比上涨 **超50%**，标记为重点关注异常趋势

- 单类错误短时间集中爆发，**10分钟内出现超50条**，触发异常告警
